## What each kernel file does

- `kernels/attention_gqa.hip`: full-attention layers: fused q / k zero-centred RMSNorm plus partial RoPE jobs that also write the K/V cache (qk_norm_rope, qk_norm_rope_jobs), then FP32 online-softmax GQA attention over the cache in scalar and WMMA forms, and gathered forms over a paged K/V (attention_gathered, attention_gathered_wmma), on a BF16 or 8-bit (kv8) cache.
- `kernels/embedding.hip`: token embedding gather from a BF16 or Q8 table into F32 or BF16 rows; an out-of-range id zeroes its row and records the first bad (position, id) in a device error word (embedding_lookup, check / report / reset_embedding_error).
- `kernels/gdn.hip`: Gated DeltaNet mixer in two launches: gdn_front (width-4 causal depthwise conv plus silu over the merged in_proj rows, beta and g gates) and delta_rule (the recurrent state update and the output rows).
- `kernels/hc.hip`: per-token hyper-connection mixes over the 4 residual streams on Q4 / Q8 weights (hc_mix_down, hc_mix_up, hc_inject); in this file hc_mix_up is instantiated for 1 to 8 tokens a block sharing each weight load (file comment).
- `kernels/hc_wmma.hip`: multi-token hyper-connection down / up mixes on the WMMA units (hc_mix_down_wmma, hc_mix_up_wmma, hc_inject_inv); the file comments describe a fused 4-stream hc_down with no DRAM partials, a 128-row up tile and loads two K steps ahead.
- `kernels/kv8.hip`: the optional 8-bit K/V cache of the full-attention layers: kv8_commit quantizes each completed 32-row group (K per channel, V per 32-channel block), kv8_dequant reads it back.
- `kernels/linear.hip`: plain BF16-weight matmul y = x W^T with FP32 accumulation (linear_bf16w).
- `kernels/linear_q4.hip`: Q4 group-affine decode GEMV (linear_q4) plus the per-token MoE expert gather, fused gather + SwiGLU and combine for Q4 and Q5 experts; the file adds exact short-M unrolling for M = 1-11 (MTP verify, file comment).
- `kernels/linear_q5.hip`: Q5 decode GEMV (linear_q5): low Q4 plane plus a 1-bit high plane; strixite builds Q5 and Q6 from one template file, linear_q56.hip.
- `kernels/linear_q6.hip`: Q6 decode GEMV (linear_q6): low Q4 plane plus a 2-bit high plane, the other half of strixite's linear_q56.hip.
- `kernels/linear_q8.hip`: Q8 decode GEMV (linear_q8) with BF16 activations through v_dot2; exact short-M unrolling for M = 1-11 (file comment).
- `kernels/linear_wmma.hip`: prefill matmul on the WMMA units for Q4 / Q5 / Q6 / Q8 and BF16 weights (linear_q4_wmma ... linear_bf16w_wmma); the file comments: Q4 / Q6 / Q8 staged as F16, Q5 as BF16 scaled codes, and a 64-row tile for Q5 and Q6 because 128 rows spill past 256 VGPRs.
- `kernels/logits_bias.hip`: adds a request's OpenAI logit_bias entries to its rows of the device FP32 logits, in place, before the top-k pick.
- `kernels/logits_topk.hip`: top-20 candidates of each logits row by rank counting, two levels of 8,192 inputs a workgroup (logits_topk).
- `kernels/moe_grouped.hip`: MoE experts for multi-token forwards: routes bucketed by expert once a layer (moe_group_routes), then grouped gather, gather + SwiGLU and combine over Q4 / Q5 expert rows; the file comments add 16-byte stores, BF16 partials through LDS and a fused combine-reduce + hc_inject_inv for prefill.
- `kernels/moe_router.hip`: per-token top-k router in registers with renormalized weights and the shared-expert slot (moe_router, moe_shared_add, moe_shared_add_inject).
- `kernels/mtp_pick.hip`: one-block reduction over the draft head's logits: argmax, runner-up value and a NaN flag, packed with the forward's error words (mtp_pick).
- `kernels/norm.hip`: zero-centred RMSNorm, its grouped form and the gated RMSNorm with a silu or sigmoid gate (rmsnorm_zc, group_rmsnorm_zc, rmsnorm_gated).
- `kernels/ple.hip`: PLE injection in two launches: ple_gate (signed-sqrt sigmoid gate per token and stream) and ple_conv (dilated causal depthwise conv).
- `kernels/qsa_indexer.hip`: QSA indexer of the full-attention layers: block keys (qsa_block_keys), relu-dot scores summed over heads (qsa_scores) and the top-k block pick (qsa_topk), with an explicit cooperative-launch path that Auto never picks (file comment).
- `kernels/residual.hip`: element-wise in-place x += y with an FP32 add and one rounding (residual_add).
- `kernels/rope.hip`: partial rotate-half RoPE in place inside the merged qkv rows, YaRN blending and interleaved mRoPE positions (rope).
- `kernels/swiglu.hip`: SwiGLU h = silu(gate) * up over [gate | up] rows (swiglu).
- `kernels/vision.hip`: the vision tower's kernels: bias-add linear, LayerNorm, GELU, position add, axial 2D RoPE on q / k, attention, embedding scatter and merge regroup (vision_*).
- `kernels/wmma.hip`: the host entry wmma_tile_product that checks the tile helpers on one tile.
